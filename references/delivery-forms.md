# 交付形式模式库(F1-F4)+ 停止条件

> 计划书第 7 节用。选形式 = 回答「这活现在该用什么形态交付」,不是「最终做成什么系统」。
> **为什么要写「停止条件」**:FDE 的单子常见的死法不是做不出来,而是**做出来了停不下来**——范围越滚越大、验证标准越来越软、经济账越算越不敢算。所以在承诺开始之前,先把「什么时候停」写死。

## 四种形式

| 形式 | 交付物 | 何时选 | 依据 |
|---|---|---|---|
| **F1 48h 薄切片** | 可跑的薄切片 | 有真实单据 + 有一线可当场验证 | 标准 FDE 交付 |
| **F2 一页纸真伪结论** | 一页纸(判断+证据+建议) | 真伪是「伪」/ 经济账算不过 | 铁律 9:失败也是产出 |
| **F3 现场工具** | 一线持续要用的脚本/工具 | 从 F1 验证过、一线还要用 | F1 升级 |
| **F4 报告/复盘** | 文字报告 | 对方只要结论不要工具 | 少做,防退化回咨询 |

## 选择规则(按顺序判断)

1. 真伪判断是「伪」?→ **F2**。一页纸告诉对方为什么伪、证据在哪、建议换什么。别硬造活。
2. 经济账算不过(连对方一个月人工都不够)?→ **F2**。把账给对方看,停或换切面。
3. 这活**之前有人做过、且说不清为什么失败**?→ **F2**。先把失败原因写成一页纸,别把失败过的方案再做一遍(问题模型「已有尝试」要素)。
4. 有真实单据 + 有一线可当场验证?→ **F1**。48h 做出薄切片。
5. F1 验证通过,一线当场说「这能帮到我」还要求接着用?→ **F3**,把切片固化成本地工具,继续换单。
6. 对方明确「只要个结论,不要工具」?→ **F4**,但要警惕——老要报告不落地 = 咨询化,别陷进去。

## 停止条件(承诺前写死,计划书第 7 节必含)

「停止条件」= **什么情况停、什么时候停**。三类都要写,缺一不算完整计划书:

| 类型 | 写什么 | 例子 |
|---|---|---|
| **范围停** | 需求长到哪就砍 | 只做快手单平台日报;一出现「再做抖音 / 看板 / 管理后台」→ 停,拉回本切片 |
| **时间停** | 到点就交付或收手 | 48h 到点,跑通即验证;单个卡点卡 >4h → 换切面,不硬扛 |
| **价值停** | 账算不过就停 | 经济账重算后月价值 < 对方一个月人工成本 → 停,交 F2 一页纸 |

**硬性一条:停止条件必须让对方也认可。** 只写在我们自己的计划里不算数。开跑前用一句话对齐:

> 到【时间 / 范围 / 指标】我们就停,到时候一起看结果。

## 关键判断词

- 选 F1 的理由,必须有:真实单据(具体是什么)+ 一线(谁,能当场评)+ 48h 内能跑通。
- 选 F2 的理由,必须有:伪在哪(证据链)或账在哪(数字来源)。
- 选 F3 的理由,必须有:一线验证过的原话证据。
- 选 F4 的理由,必须有:对方明确只要结论。没这句话就别选 F4。
- 停止条件的理由,必须有:范围/时间/价值**至少两类**,且是对齐过的。

## 后续怎么续(换单口径)

- F1 验证过 → 下一个切片:从验证现场听到的「那能不能也…」里挑一个。
- F2 → 建议对方换切面/换现场,不硬续。
- F3 → 固化工具 + 培训一线 + 继续换单。
- F4 → 复盘结论写清楚,不承诺工具化。

## 反面案例(别这样选)

- 有真实单据、有一线,却选 F4 只出报告 → 退化回咨询,砍。
- 真伪是伪,却选 F1 硬做 → 浪费 48h,砍回 F2。
- 一线没人验证,却选 F3 做工具 → 没人用的工具,砍回 F1 先验证。
- 没写停止条件就开工 → 范围失控、到期收不了手,砍,补第 7 节再开跑。
