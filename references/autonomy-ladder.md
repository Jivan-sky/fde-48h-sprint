# 任务自主性阶梯：规则 → 工作流 → Skill → Agent → 人工

> Phase 5/6/7 做任务分解时逐任务使用。目标不是「尽量多上 Agent」，而是选**最低充分复杂度**。
> 一句话：**能规则就规则，能工作流就工作流，能 Skill 就 Skill，只有多步、工具、异常、非结构化输入同时存在时才上 Agent。**

## 五级阶梯

| 级别 | 适合什么 | 不适合什么 | 典型产出 | 风险 |
|---|---|---|---|---|
| **0 规则/脚本** | 输入结构稳定、结果可计算、同样输入要同样输出 | 非结构化输入、需要语义判断 | 校验脚本、计算脚本、批处理 | 规则覆盖不全；输入漂移 |
| **1 工作流/RPA** | 步骤固定、跨系统搬运、少量判断 | 异常分支多、界面频繁变化 | 流程编排、连接器、队列 | 脆弱；异常会卡住 |
| **2 Skill** | 知识、方法、格式、判断规则为主 | 需要实时多步工具调用 | `SKILL.md` + 例子 + eval | 经验过时；边界不清 |
| **3 Agent** | 多步骤、要调工具、有状态、有异常分支、输入非结构化 | 确定性计算、不可逆高风险决策 | agent + 工具 + 状态 + 人工兜底 | 成本、漂移、越权、难评估 |
| **4 纯人工** | 不可逆、高风险、关系/责任/价值判断 | 高频重复、规则明确 | SOP + 审批 + 记录 | 产能瓶颈；不一致 |

## 选择问题（逐任务问）

1. 输入是结构化字段，还是自然语言/文档/图片？
2. 输出是否必须完全确定？同样输入能否允许不同答案？
3. 步骤是否固定？有没有需要临场决定下一步的分支？
4. 是否需要调多个工具、读多个系统、维护状态？
5. 异常比例多高？异常能否枚举？
6. 出错代价多大？可逆吗？是否需要人审批？
7. 数据是否可得、权限是否清楚、能否进模型？
8. 有没有 20 个真实案例可以做 eval？
9. 谁对最终结果负责？谁处理例外？

## 选择规则

- 输入结构化 + 输出确定 → **规则/脚本**；不要上 Agent。
- 跨系统但步骤固定 → **工作流/RPA**；先把交接契约写清。
- 主要靠经验/方法/格式 → **Skill**；把判断规则、反例和验收写进去。
- 多步 + 工具 + 状态 + 异常 + 非结构化输入 → **Agent**；先只读/草拟，再逐步放开写入。
- 不可逆、高风险、法律责任 → **纯人工或人工审批**；AI 只做辅助材料。
- 没有 eval、没有 owner、没有例外队列 → **不要自动化到写入**；最多只读/草拟。

## Agent 适配清单

适合 Agent：

- 高频、重复、但每次细节不同；
- 输入是文档/聊天/邮件/网页等非结构化内容；
- 需要多步工具调用和中间判断；
- 成功标准可写成 eval；
- 失败可回滚或有人工复核；
- 有明确的工具、数据、权限和 owner。

不适合 Agent：

- 纯计算、纯校验、纯格式转换；
- 付款、审批、删除、对外发送等不可逆动作；
- 数据源不稳定、权限不清、没有审计；
- 没有真实案例、没有 eval、没人兜底；
- 只是把原来的人工步骤换成聊天框。

## 推荐架构：AI at the edge，deterministic core

```text
非结构化输入
   ↓
AI 抽取/分类/草拟/建议
   ↓
规则校验/计算/权限/限额
   ↓
稳定执行（工作流/脚本）
   ↓
例外队列（人处理 + SLA + 反馈）
```

AI 负责把不确定性收敛成结构化结果；规则和工作流负责稳定执行；人负责不可逆和高价值判断。不要让 AI 直接承担「必须一模一样」的确定性决策。

## S/P 轨道怎么用

- **S 轨道**：只给一个任务选一级，48h 做 F1 薄切片；不要在一个切片里塞五级能力。
- **P 轨道**：先做全链路任务清单，再逐任务定级；pipeline 是混合结构，不是「一个超级 Agent」。
- 任何一级都要有 eval、失败处理、人工兜底和成本口径；级别越高，控制越重。

## 反模式

- Agent-first：先决定用 Agent，再找任务；
- 一个全能 Agent 包打整条流程；
- 用 AI 做确定性计算或不可逆审批；
- 把异常全部丢给业务，不建队列/SLA；
- 没有 eval 就上线；
- 只算模型成本，不算人工复核、异常处理和运维成本。

## 自检

- 这个任务为什么不能用规则/工作流/Skill？
- 它真的需要多步工具调用和临场判断吗？
- 失败可逆吗？谁处理例外？
- 有没有 20 个真实案例可以验收？
- 如果去掉 Agent，业务会损失什么？这个损失能量化吗？
