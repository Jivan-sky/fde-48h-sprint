# 接口与数据勘测:直连 / 人肉桥 / 不通

> Phase 4 用。目标:在写任何设计之前,先确认「切片吃什么、怎么拿、拿不到怎么办」。接口不通的漂亮设计是废纸(原则「接口数据先行」)。
>
> **D1/D2 追加**:除了「有没有接口」,还要确认「这个环境能不能到达接口、数据能不能进模型、审批要多久」。沙盒能通 ≠ 生产能通。

## 勘测清单(每条数据流逐项问)

1. 数据在哪?(后台 / 数据库 / 第三方 / 纸质 / 人口头)
2. 谁有权限?你能拿到吗?
3. 能调 API 吗?有没有 token/key?谁批准?
4. 只能导出吗?导出格式是什么?(xlsx / csv / pdf / 截图)
5. 频率?实时 / 每天 / 每周 / 要的时候才导出?
6. 体量?几千行还是几十万行?
7. 编码坑?Windows GBK vs UTF-8?
8. 有没有真实样例单据?**拿到了吗?**
9. **环境可达性**:内网/VPN/代理/外网出口/白名单域名/气隙?脚本和 Agent 本身能在目标环境跑吗?不能时由谁执行?
10. **数据分级与流向**:L0-L4 哪一级?出不出客户环境?是否跨境?保留/删除要求?
11. **模型可用性**:数据能否进模型?哪个端点/区域/版本?RAG 语料/索引/embedding 放哪?供应商是否保留/训练?
12. **审批提前期**:权限/接口/模型/数据申请通常几天?卡在谁?有没有并行路径?
13. **副作用与可追溯**:这条数据流是否伴随写入、导出、对外发送、权限/配置变更?有没有审计、撤销、快照、恢复演练、外部副作用撤回能力?结论落五档;未知按不可写。

## 三档判定

| 档 | 含义 | 切片影响 |
|---|---|---|
| ✅ 直连 | 有 API 或可自动导出(定时/脚本) | 切片可以全自动 |
| ⚠️ 人肉桥 | 手工导出/复制粘贴/截图 | 切片输入依赖人,考察期内可接受,长期要换 |
| ❌ 不通 | 无权限/无接口/纯纸面 | 切片没输入 → 换数据源,或交付 F2 |

**环境可达性单独判**:即使有 API,如果目标环境不能出网/不能装客户端/证书不受信,也按 ❌ 或 ⚠️ 处理,不能写「直连」。

## 卡点类型表(每个卡点带证据)

| 卡点 | 样子 | 预案 |
|---|---|---|
| 权限墙 | 数据在别人手里,不给你 | 问谁批;批不了 → 换公开数据/换切面 |
| 审批等待 | 权限/模型/数据申请一周没批 | 单列关键路径;并行做脱敏样本/沙盒;不把等待伪装成技术卡点 |
| 网络不可达 | 内网无出口/代理拦截/证书不受信/气隙 | 客户跳板机/离线包/本地模型;不可达就是 ❌,不假设「应该能通」 |
| 格式漂移 | 每次导出格式不一样/列名变 | 解析层宽容解析 + 异常清单 |
| 无校验 | 数据没主键/两份对不上 | 对账键缺失 → 输出带「可疑行」 |
| 编码坑 | GBK 乱码 | 一律显式 `encoding="utf-8"`,探测失败标待确认 |
| 体量超载 | 几十万行 Excel 打不开 | 抽样 1000 行验证,全量走流式 |
| 限流/风控 | API 限流、登录风控 | 降频、缓存、退人工导出 |
| 模型不可用 | 无批准端点/数据不能进模型/区域限制 | 本地模型/规则/人工;不得偷偷切未批准端点 |

## 数据可处理性(能不能处理)

- 字段完整吗?关键字段(时间/金额/ID)有没有?
- 有对账键吗?(能把两份数据对上的唯一键)
- 时间口径一致吗?(东八区/UTC、自然日/工作日)
- 脏数据比例?(空值/重复/错位)
- 结论分三档:**可直接处理 / 需要清洗(列出清洗规则)/ 不可处理(缺关键字段,标待确认)**

## 纪律

1. 真实单据优先:没拿到样例单据之前,一切字段都是「待确认」;D0 合成/公开样本、D1/D2 批准样本都要标来源与批准状态。
2. 没摸到的接口/权限,写「未摸到」,不脑补「应该能调」。
3. 每个卡点必须有预案;没有预案的卡点 = 负面检查命中。
4. 审批提前期必须写进关键路径;审批等待不是技术卡点,不能用「换切面」掩盖。
5. D1/D2 的「直连」必须同时满足:有接口 + 目标环境可达 + 鉴权合法 + 数据边界允许;缺一不可。
6. **不导出 HAR、不保存完整请求/响应**:只记录方法、脱敏路径、参数名/类型、响应字段轮廓和错误轮廓;客户提供的已批准脱敏导出可作为样本,但要标来源和批准状态。
